# 多任务并行演练（4 快 + 4 慢双通道）

验证调度机制的四件事，纯脚本可复现（无 LLM 依赖）：

1. **双通道并行有效**：8 任务串行总和 vs 并行墙钟，加速比 ≈ 2×（2+2 worker 的理论上限）
2. **隔离性**：每任务独立 git worktree，互相看不到对方的文件（污染检查 = 列出 worktree 里非本任务的 mod_* 文件）
3. **闸门全跑**：每任务真执行 verify（G1）+ scripts/gate.py（G3/G4/G6/G7）
4. **快通道不被饿死**：快任务最慢完成时间 ≪ 慢任务

```bash
python3 run.py
# 期望末尾：✅ 并行调度符合预期，退出码 0
```

实测参考输出（2026-11-13）：

- 串行总和 4.49s / 并行墙钟 2.13s / 加速比 2.11×
- 快通道最慢任务 0.06s（慢任务 1.06s 在跑时它早已完成）
- 8/8 任务 verify 绿 + gates 过 + 零污染

## 对应真实编排的映射

| 演练里的 | 真实编排里的 |
|---|---|
| fast/slow 通道 | 小改动走快通道、集成类走慢通道 |
| verify 里 sleep | 真实的长耗时测试/构建 |
| 每任务独立 worktree | G7 硬闸门 |
| 2 worker/通道 | 并发上限（防 API 限流与机器过载） |
