# 闸门清单（硬约束）

> 原则：**能写成代码的，不要写成提示词。**

| 编号 | 闸门 | 落地方式 |
|---|---|---|
| G1 | 测试/构建必须绿 | CI 或本地 verify 命令，退出码非 0 即阻断 |
| G2 | Reviewer 必须 pass | 独立模型判，`reject` 即阻断合并 |
| G3 | 改动不得超出 handoff 声明 | diff 文件列表与 `files` 求差集 |
| G4 | 不得删除或跳过测试 | diff 中出现 `-def test_` / `skip` 即报警 |
| G5 | 单任务重试 ≤ 3 | 计数器，超限标 `failed` |
| G6 | 单任务 token 预算 | 超预算即停并落盘用量 |
| G7 | 独立 worktree | 每个任务 `git worktree add` 独立目录 |

## 工具权限（建议 deny）
- 删除仓库外文件
- 修改 CI / 发布流程配置
- 强制推送
- 读取密钥目录
- 访问生产环境

## 熔断
连续 3 个任务 `failed` → 停掉整条流水线，等人看。
